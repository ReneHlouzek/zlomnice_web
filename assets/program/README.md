# Stránky programu

Do této složky vložte jednotlivé obrázky stran programu v tomto pořadí:

- `01.png`
- `02.png`
- `03.png`
- …
- `12.png`

Web je načítá automaticky. Na desktopu se zobrazují dvě strany vedle sebe a listují se animací otočení stránky. Na telefonu se zobrazuje vždy jedna strana a listování funguje tlačítky i gestem swipe.

Pokud bude program mít více než 12 stran, stačí upravit počet v `script.js`.
